# Programming Design and Data Structure Labs

## 项目的基本介绍

是保存大一程序设计和大二数据结构的作业的库。

## 文件夹内容

- c++作业：包含各种C++编程练习题。
- c++_project：c++期末大作业相关的源代码文件。
- structure_homework：数据结构相关习题及解答。
- structure_project：数据结构实验课相关习题。
- 修笔记：学习笔记及相关资料。
- hot100：LeetCode 热题 HOT 100 的 C++ 题解，按算法类型分类整理。

## hot100 目录结构

题解以 LeetCode 题号命名（如 `binary_search/33.cpp`），按专题分目录：

| 目录 | 题量 | 说明 |
| --- | --- | --- |
| binary_tree | 14 | 二叉树遍历、递归与路径问题 |
| linked_list | 11 | 链表操作、双指针与环形检测 |
| traceback | 9 | 回溯：排列、组合、子集、棋盘 |
| dynamic | 5 | 动态规划：线性 DP、背包 |
| list | 5 | 数组与区间操作 |
| map | 5 | 哈希表 / 映射计数 |
| stack | 5 | 单调栈、括号匹配 |
| binary_search | 4 | 二分查找与旋转数组 |
| greed | 4 | 贪心策略 |
| matrix | 4 | 矩阵遍历与原地修改 |
| double_pointer | 3 | 双指针：三数之和、盛水容器 |
| haxi | 3 | 哈希：最长连续序列、字母异位词 |
| heap | 3 | 堆与 Top-K 问题 |
| switch_window | 2 | 滑动窗口 |
| son_list | 1 | 子序列问题 |

另有 `hot100/复习备忘录.md`，记录各专题的解题思路与易错点。

## 说明

- 题解均为 C++ 实现，可直接编译运行。
- `.gitignore` 已忽略编译产物（`*.exe`）与 `.vscode/` 配置目录。
