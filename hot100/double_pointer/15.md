# 三数之和 核心极简关键点

## 1. 预处理

数组**先排序**，才能用双指针+方便去重。

## 2. 外层i循环（固定第一个数）

1. 必须 `i>0` 才可以判重：`nums[i]==nums[i-1]` 就跳过，**防i重复**；
2. 目标：找两数之和等于 `-nums[i]`。

## 3. 内层双指针 j=i+1，k=末尾

循环条件**只能 j < k**，保证 i<j<k 下标合法不复用元素。

- 和偏大：左移k
- 和偏小：右移j
- 和刚好相等：存入结果

## 4. 命中答案后固定步骤（最容易错）

1. 先 `j++`、`k--` 抛弃当前用过的一组下标；
2. 再去重，**每条去重while必须前置 `j<k`**，防止数组越界：
   - j向右走，对比左边旧值：`nums[j] == nums[j-1]`
   - k向左走，对比右边旧值：`nums[k] == nums[k+1]`

## 5. 三大红线禁忌

1. 不能先去重再挪指针；
2. 去重不加 `j<k` 一定会下标越界报错；
3. 不能用 `j <= k`，会出现同一个元素选两次。

## 6. 核心思想

排序固定首元素，剩余区间相向双指针缩小范围，三层去重（i/j/k）保证答案无重复三元组。
