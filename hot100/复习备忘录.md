## 一、你已经形成的解题框架（通用心法）

### 1. 递归四步法（链表、二叉树通吃，出自 linked_list/note.md）

1. **定终止条件**：空节点 / 单节点，直接 return
2. **递阶段**：只深入，不处理逻辑，把后续全部交给下层
3. **归阶段**：写核心逻辑（重中之重）
   - 改结构：反转 next 指针
   - 比对数值：头尾节点校验、移动正向指针
4. **设计返回值**
   - 改链表：永远返回处理后的新头
   - 校验类：返回布尔值，错误逐层向上传递

### 2. 两类链表递归（出自 linked_list/note.md）

| 类型 | 典型题 | 特点 |
|---|---|---|
| 结构修改类（翻转指针） | 206 反转、24 两两交换 | 无需全局变量；每层统一返回原链表尾（新头） |
| 逆序读取比对类 | 234 回文、倒数第k节点 | 设一个**全局正向指针**，递归压栈=从尾遍历，首尾配对校验 |

递归适用性：✅ 需要**从后往前访问**链表、追求简洁且链表不长；❌ 链表很长（栈溢出）、面试要求 O(1) 空间（必须迭代）。

### 3. 「成员变量 + 辅助函数」骨架

你的绝大多数题都是这个形状：`res` / `now` / `target` 等放成员变量，主函数只做初始化和调用私有递归函数。
好处是函数签名简单、状态共享方便；注意面试时主动说明成员变量的含义。

### 4. 先暴力再优化的刷题路径

多道题你先写了暴力 AC，再在注释里记录优化方向（如 560 注释写"前缀和+哈希表"但代码还是 O(n²) 暴力）。
这是好习惯，但**面试手撕要能直接写出优化解**——第五节的待重写清单就是为此准备的。

## 二、分专题要点

### 1. 哈希 —— [49](haxi/49.cpp) [128](haxi/128.cpp)

- **49 字母异位词分组**：排序后的串作 key（`unordered_map<string, vector<int>>`），同 key 归组。
- **128 最长连续序列**：核心技巧 = 只从**序列头**开始扩展——`st.count(cur-1)` 为真说明不是开头，直接跳过。每个数最多被访问两次，O(n)。
  - 自己的教训注释："哈希表自动去重，第二次遍历表即可，继续遍历顺序表会超时" → **去重后遍历哈希表本身，不要遍历原数组**。

### 2. 双指针 —— [11](double_pointer/11.cpp) [15](double_pointer/15.cpp)

- **11 盛水容器**：相向双指针，每次移动**较短的板**（移动长板不可能让结果变大）。
- **15 三数之和**：先排序 → 固定 i 枚举 → 剩余区间 j/k 相向。自己的口诀：
  - i 判重必须 `i>0 && nums[i]==nums[i-1]` 才跳过；
  - 循环条件只能 `j < k`；
  - **命中答案后固定步骤（最容易错）：先 `j++`/`k--` 抛弃用过的一组，再去重，每条去重 while 必须前置 `j<k` 防越界**。
  - 三大红线：不能先去重再挪指针；去重不加 `j<k` 必越界；不能用 `j<=k`（同元素选两次）。
  - ⚠️ 当前 [15.cpp](double_pointer/15.cpp) 里去重 while 还没加 `j<k` 保护（见第五节 Bug 清单）。

### 3. 滑动窗口 & 子串 —— [3](switch_window/3.cpp) [438](switch_window/438.cpp) [560](son_list/560.cpp)

- **438 找异位词**：定长窗口 + 两个 26 长度计数数组，窗口滑动时 `cur[出]--, cur[入]++`，直接比较数组是否相等。注意特判 `p.size() > s.size()`。
- ⚠️ **3 无重复最长子串、560 和为K子数组目前是暴力占位版**，面试标准解未落地：
  - 3 标准解：滑动窗口，`unordered_set` 记录窗口内字符，右端遇重复则左端收缩删除直到无重复；
  - 560 标准解（你自己注释里已写）：前缀和 + 哈希，`mp[prefix]++` 边扫边查 `prefix - k` 出现次数。**前缀和哈希要在加入当前前缀之前查询**，且初始 `mp[0]=1`。

### 4. 数组 DP 与区间 —— [53](list/53.cpp) [56](list/56.cpp) [189](list/189.cpp) [238](list/238.cpp)

- **53 最大子数组**：DP 定义"**以 i 结尾**的最大和"，转移 `cur = max(frontmax[i-1]+nums[i], nums[i])`，全局再取 max。（可优化成 O(1) 空间的滚动变量）

- **238 除自身的乘积**：L/R 前后缀分解思想——`res[i] = 左边所有积 × 右边所有积`。（当前实现有下标越界问题，见第五节）

### 6. 栈 —— [20](stack/20.cpp) [155](stack/155.cpp) [394](stack/394.cpp) [739](stack/739.cpp)

嵌套栈解题笔记（stack/note.md，精华）：

> 递归：系统栈自动保存现场；迭代栈：**手动保存现场**。
> 栈存什么？不限于字符，保存**整套被暂停的状态**（旧结果、参数）。
> 流程：左边界 → 压栈存旧状态并清空当前状态；普通字符 → 更新当前状态；右边界 → 出栈合并新旧结果。
> 想不出迭代，先写递归。**递归函数的局部变量，就是栈里面要存的数据。**

- **20 有效括号**：map 存配对 `{(, {, [`，遇到右括号查栈顶是否匹配；结束栈非空也 false。
- **155 最小栈**：双栈同步 push，min 栈压 `min(旧min, value)`。教训注释：**第一次入栈时 min 栈为空，不能直接访问 top()，要单独处理**。
- **394 字符串解码**：`stack<pair<int,string>>` 存倍数+旧串，正是"手动保存现场"模板的实现。
- **739 每日温度**：单调栈（存下标），流程即自己注释："每到一个下标先处理栈中没有找到更大值的元素，最后再把当前下标入栈"。⚠️ 当前实现 i 从 1 开始漏了下标 0（见第五节）。

### 7. 堆 / 快速选择 —— [215](heap/215.cpp)

QuickSelect 划分模板极简笔记（heap/note.md，全文背诵）：

> **Hoare 双向划分**：i=l-1, j=r+1；双 do-while；**无需 pivot 归位**；区间 `[l,j]` / `[j+1,r]`；✅ 禁止 j-1；重复元素性能好。
> **Lomuto 单向划分**：单遍历 for；末尾 swap；**pivot 固定落在 j**；区间 `[l,j-1]` / `[j+1,r]`；✅ 使用 j-1；大量重复数据易超时。
> 口诀：Hoare 双向不归位，分界不用减一；Lomuto 单向归位 pivot，左区间 j 减一。
> **两套边界严禁混用；partition 只负责返回分界，递归交给上层 quickSelect。**

215 的实现要点：随机选 pivot（`rand()%(r-l+1)` 再换到 r）防退化；本题划分方向是"大的在左"（do-while 条件 `nums[i]>pivot`），所以**第 k 大就落在下标 k-1**，递归到 `j` 与 `target=k-1` 的大小关系决定走哪半边。平均 O(n)。

### 8. 二分查找 —— [33](binary_search/33.cpp) [34](binary_search/34.cpp) [74](binary_search/74.cpp) [153](binary_search/153.cpp)

统一骨架：`while(left <= right)` + `mid = left + (right-left)/2`（防溢出）。

- **34 排序数组中找范围**：**两趟二分找边界**（自己注释："一次当作大于等于，一次当作小于等于处理，只有等于时才记录"）：找左边界时命中 target 记录并 `right=mid-1` 继续向左收；找右边界对称。
- **33/153 旋转数组**：关键判断 = **mid 和 left 比较，确定哪半是有序的**；再判断 target 在不在有序那半的范围内。33 里还有 `nums[mid]==nums[left]` 时 `left++` 的兜底（可处理重复元素）。
- **74 二维矩阵**：两次二分——先对每行首元素二分定位行，再行内二分。
- **153 找最小值**：以 `nums[0]` 为参照，mid ≥ 参照值说明最小值在右边，否则记录 mid 并向左收。

### 9. 链表 —— [2](linked_list/2.cpp) [19](linked_list/19.cpp) [24](linked_list/24.cpp) [24_1](linked_list/24_1.cpp) [138](linked_list/138.cpp) [146](linked_list/146.cpp) [148](linked_list/148.cpp) [160](linked_list/160.cpp) [206](linked_list/206.cpp) [234](linked_list/234.cpp)

- **哑节点（哨兵）心得**，来自 [2.cpp](linked_list/2.cpp) 底部的踩坑实录（原文）：
  > 开头指针没赋值，是随机乱地址，访问直接报错；
  > 节点建在临时空间里，用完就销毁，指针指向失效内存；
  > 循环条件不对，没法算完两条链表所有数字，加法进位计算顺序写错，最后多出的进位也没补上。

  结论：**自己装填链表返回时，用不动的哨兵节点记录开头；哨兵必须是实体（`ListNode dummy(0)`），不能只用指针**；循环条件要把进位也算进去（`|| add != 0`）。
- **24 两两交换**：迭代版口诀"靶节点 pre、当前 cur、下一个 nex"，四步 `cur->next=nex->next; nex->next=cur; pre->next=nex; pre=cur;`；递归版更短：先存 res=第二个节点，递归处理后面，归的时候接回去。**一题两版对照着记**。
- **19 倒数第 n 删除**：思路已写（快指针先走 n，然后同步走）⚠️ 但函数体还没实现（见第六节）。标准写法：哑节点 + 快慢指针，快走到末尾时慢的下一个就是要删的。
- **138 复制带随机指针**：哈希存 `旧→新` 映射跑两遍（第一遍建节点，第二遍接 random）。进阶（自己注释）："迭代穿插，在每个旧的后面依次插入新的，省下哈希空间" O(1) 空间版。
- **146 LRU**：双向链表 + 哈希。要点（自己注释）：构造时**先把头尾哨兵互连**；get 命中就把节点搬到头部；put 满容量时**删链表节点的同时必须删哈希表**；新增一律插头部。
- **148 排序链表**：快慢指针找中点（判空次序 `fast->next && fast->next->next`，保证偶数长度时前半段短）、`slow->next=NULL` 断开、递归归并；合并时用哑节点直接连，无需断开原链表后续节点。

- **206 反转链表**：递归版已写熟；**迭代三指针版（pre/cur/nex）只有一行思路注释，面试高频，务必练到闭眼能写**。

### 12. 回溯 —— [17](traceback/17.cpp) [22](traceback/22.cpp) [39](traceback/39.cpp) [46](traceback/46.cpp) [46_1](traceback/46_1.cpp) [78](traceback/78.cpp) [79](traceback/79.cpp) [131](traceback/131.cpp)

三大模板（traceback/note.md，原文背诵）：

**① 子集式（每个元素独立选/不选）**——78 子集、39 组合总和：

```cpp
void dfs(int cur, int n) {
    if (cur == n) { /* 记录答案 */ return; }
    t.push_back(cur); dfs(cur + 1, n); t.pop_back();  // 选
    dfs(cur + 1, n);                                   // 不选
}
```

39 的变体：可以重复选同一个数 → "选"分支递归时 `cur` 不前进；剪枝：`sum > target || cur >= size` 直接返回。

**② 普通 for 式（每层从某个起点往后枚举选择）**：

```cpp
void backtracking(参数) {
    if (终止条件) { 存放结果; return; }
    for (选择 : 本层集合中的元素) {
        处理节点;
        backtracking(路径, 选择列表);
        撤销处理;
    }
}
```

- 46 全排列两种写法对比（自己注释）："可以通过交换前后位置直接完成，不必新建这么多变量储存，每次循环交换当前调整位置的数字和循环到的数字"——visited 数组版直观，swap 原地版省空间，两版都要会。
- 22 括号生成：剪枝规则 `right > left` 才能放右括号（剩余右括号多于剩余左括号）。
- 79 单词搜索：网格回溯，`passed[x][y]=true` 递归后 `=false` 恢复现场；方向数组四连。

**③ 分割式（把序列切成连续若干段）**——131 回文分割（93 复原 IP 同款）：

判断依据：答案是**连续切分**，每元素恰好属于某段，枚举的是"当前段的结束位置 end"，下一段从 `end+1` 开始。要点（自己笔记原文）："start 是『下一段必须从哪开始』，这是贯穿递归的状态；不要用『继续拼 vs 切开』两层递归去写，直接枚举结束位置最清晰。"

## 四、自查发现的 Bug（读你代码时发现，面试前务必修）

1. **[739.cpp:10](stack/739.cpp#L10)** — 循环从 `i=1` 开始，**下标 0 从未入栈**，`res[0]` 恒为 0（例：`[1,2]` 应输出 `[1,0]`，现在输出 `[0,0]`）。改成 `i=0` 即可。

3. **[238.cpp:19](list/238.cpp#L19)** — 后缀积循环 `for(int i=len;i>=0;i--)` 第一步就读 `nums[len]` **数组越界**，且污染之后所有乘积。应改为 `i=len-1`。

## 六、手撕临场 Checklist

拿到题先说再做：

1. **先确认题意和边界**：空输入？单元素？全相同元素？负数？（你的踩坑史：全相同触发三数之和越界、空 min 栈 top、进位残留）
2. **先报复杂度目标**再动手："这题我打算用 O(n) 时间 O(n) 空间的哈希做法"。
3. **链表题先画图**：标出 pre/cur/nex 三个箭头怎么改，再写代码；涉及删头/插头一律上哑节点。
4. **递归题先说终止条件**，再说"递阶段做什么、归阶段做什么"（你的四步法），说完再落笔。
5. **网格/矩阵题先写方向数组和边界检查**，这两块写对了题就成了一半。
6. **回溯题先判断类型**：独立选/不选 → 子集式；连续切段 → 分割式；每层枚举 → for 式。
7. **写完主动过一遍极端用例**：拿一个最小例子人肉跑一遍循环（尤其是 while 边界、去重位置、最后一段/最后一个元素有没有结算——合并区间最后补 push 的教训）。
8. **被要求优化时**：先想哈希降一维（两数之和→哈希、和为K→前缀和哈希），再想排序+双指针/二分，再想单调栈/单调队列。
