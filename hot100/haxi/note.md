# 哈希表笔记

## 一.用法

1.创建

```c++
unordered_set<int> st;     //快速查有没有
unorderde_map<int,int> mp   //键值对
```

2.查找

```c++
//有无，个数
st.count(2);
mp.count(2);

//位置
auto it=st.find(3);
if(it !=st.end()){}//是否存在

auto it =mp.find(3);
```

3.增删查改

```c++
st.erase(3); //确定有这个元素
st.erase(st.find(3));  //不确定是否有，保险写法
```

## 顺序表（数组/vector）适用

1. 数据范围小、下标连续规整；
2. 需要有序遍历、随机下标访问；
3. 追求访问速度、内存效率优先。
优点：存取稳定高速、天然有序；缺点：数值跨度大会浪费大量空间。

## 哈希表（unordered_map/set）适用

1. 数值零散跨度大、正负无规律；
2. 字符串充当索引；
3. 核心需求：快速查找、去重、键值配对计数，不要求顺序。
优点：按需分配内存，增查平均O(1)；缺点：无序，存在哈希碰撞开销。

## 速记口诀

范围规整用数组，零散查找选哈希。

## 一、头文件

- `map`：有序红黑树，`#include <map>`
- `unordered_map`：哈希表，`#include <unordered_map>`

## 二、定义 + 直接初始化（最常用）

定义同时批量插入数据，刷题首选

```cpp
map<int,string> mp = {
    {1,"a"},
    {2,"b"}
};
```

## 三、三种插入方式

### 1. 下标赋值 `mp[key] = value`

```cpp
mp[3] = "c";

```

- key不存在：新增键值对
- key已存在：**覆盖原有value**

### 2. insert 插入（不覆盖）

```cpp
mp.insert({4,"d"});
mp.insert(make_pair(5,"e"));
```

- key不存在：新增
- key已存在：**不修改、不覆盖**

## 四、核心区分

- `mp[key] = val`：支持新增+更新，允许覆盖
- `mp.insert()`：仅新增，不会覆盖旧数据

## 五、补充说明

`unordered_map` 初始化、插入语法和 `map` 完全一致，仅底层存储结构不同。
