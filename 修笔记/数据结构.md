## 排序大法

### 1.插入排序

(1) 直接插入 O(n^2)

- 从第二个元素开始依次与前面元素比大小，然后插入
  
(2) 折半插入 O(n^2)

- 从第二个元素开始依次与前面比大小，但折半比较，然后插入

(3) 希儿排序  **不稳定**

- 选定一个增量序列{dn……d2,d1}且使d1=1，每次将相隔dn的两个数相比较，交换，dn一直递减到1。
  
### 2.选择排序

(1) 简单选择排序 O(n^2)

- 从第一个数开始每次将当前数与后面最小的数交换
- 空间复杂度小
  
(2) 堆排序???(没讲)

### 3.交换排序

(1) 冒泡排序 O(n^2)

- 从末尾开始依次比较相邻两个元素大小，每次循环产生一个排好的元素
  
(2) 快速排序 理想：O(nlogn) 最慢：O(n^2)  **不稳定**

- 选取最后一个元素为轴点
- 从前向后扫描直至找到大于等于轴点的元素i
- 从后向前扫描直至找到小于轴点的元素j
- 交换扫描i和j
- 继续扫描
- 全部交换完后交换轴点和i
- 分别对轴点前后的部分重复上述操作

### 4.归并排序

- 将序列分成小的子序列(最小为一个元素)然后将有序子序列一层一层进行归并。

## 树

### 性质

1.叶结点个数等于度为2的结点个数+1
2.深度为d的二叉树最多有2^d-1个结点
3.完全二叉树结点k满足：
    (1)左子结点2k,右子结点2k+1
    (2)父结点k/2

### 二叉树

#### 构造二叉树算法

```c
struct BinaryTreeNode{ //结构体定义
    int value;
    BinaryTreeNode* left;
    BinaryTreeNode* right;
    BinaryTreeNode(int val=0):value(val),left(NULL),right(NULL){}; //构造函数
};
//构造树结点函数，返回结点的地址
BinaryTreeNode* CreateBinaryTree(value,BinaryTreeNode* left_tree,BinaryTreeNode* right_tree){
    BinaryTreeNode* tree=new BinaryTreeNode();
    tree->value=value;
    tree->left=left_tree;
    tree->right=right_tree;
    return tree;
}
```

#### 递归算法求树高度

```c
#include<algorithm>//必加，用于比较大小
int Height(BinaryTreeNode* tree){
    if(tree=NULL){
        return 0;
    }
    else{
        h_left=Height(tree->left);
        h_right=Height(tree->right);
        return max(h_left,h_right)+1;
    }
}
```

#### 非递归遍历算法

```c
#include<stack>
//前序遍历
vector<int> PreOrder(BinaryTreeNode* tree){
    stack<BinaryTreeNode> s1;
    vector<int> result;
    while(tree!=NULL && !s1.empty()){//树不空或栈不空
        while(tree!=NULL){      //树不空时先往下遍历
            result.push_back(tree->value);
            s1.push(tree);      //取完值入栈
            tree=tree->left;    //遍历左子树
        }
        if(!s1.empty()){       //树空时开始处理栈中
            tree=s1.top();      
            s1.pop();
            tree=tree->right; //遍历栈中结点的右子树
        }
    }
}
//中序遍历需将访问环节放到处理栈中树的第一步取得栈顶结点之后进行
//入栈，左节点为空->出栈同时输出，右节点空继续出栈，右节点不为空入栈
```

#### 层序遍历算法

```c
include<queue>
vector<int> LevelOrder(BinaryTreeNode* tree){
    vector<int> result;
    queue<BinaryTreeNode> que;
    que.push(tree)
    BinaryTreeNode* cur;
    while(!que.empty()){
        cur=que.back();
        que.pop();
        result.push_back(cur->value);
        que.push(cur->left);
        que.push(cur->right);
    }
    return result;
}
```

### 哈夫曼树

#### 定义

给定一组叶结点权重，由此构建的所有带权二叉树中，带权路径长度最小的二叉树

#### 基本性质

1.最优二叉树（哈夫曼树）是满二叉树
2.最优二叉树中，如果两个叶结点的权重值不同，则权重值小的叶结点在树中的层数大于等于权重值大的叶结点
3.给定一组叶结点权重，存在最优二叉树，权重最小和次小的叶结点在树的最下层并且互为兄弟结点

#### 哈夫曼算法

一种至下而上构建最优二叉树的方法，通过不断合并两个最小带权二叉树，最终生成最优二叉树

```c
#include<queue>//利用c自带的队列
priority_queue<int> a//最大堆
priority_queue<int,vector<int>,greater<int>> a//最小堆
```

## 折半查找

```c
//此代码用于查找数字第一次出现的位置
int cha(const vector<int> &a,int b){
    int qian=0,hou=a.size()-1;
    int res=-1;
    while(qian<=hou){
        int mid=(qian+hou)/2;
        if(a[mid]==b){
            res=mid+1;
            hou=mid-1;      //找到后不急于输出而是先保存，继续查找左侧是否有相同
        }
        else if(a[mid]>b){
            hou=mid-1;
        }
        else if(a[mid]<b){
            qian=mid+1;
        }
    }
    return res;
}
```
